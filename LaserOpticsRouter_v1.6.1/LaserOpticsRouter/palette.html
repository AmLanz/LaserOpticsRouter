Prisms and paired rays

h is local left, v is local up: for a +X beam they mean +Y and +Z. A trailing minus reverses the side; a leading minus still means small size. Wollaston uses half the specified angle on each side. Rochon keeps the main beam straight. The specified separation is fixed; wavelength-dependent birefringence and polarization are not simulated.

p advances both rays by the stated distance along their own directions. Other optics act on the main ray; use an output endpoint in another line for independent optics. Previous line end carries the pair; copying one endpoint carries only that ray. One pair is supported per line chain: start from an individual endpoint before using another splitting prism/displacer.

_bd combines a matching, active pair in the same line or a Previous line continuation. It checks position and direction within 0.001 mm / 0.001°. It cannot recover a second ray from a single copied endpoint. Matching envelopes are drawn once after recombination; differing envelopes remain visible on the common axis. Main/secondary endpoints retain separate per-arm losses, GDD and lengths. Select one arm in the calculator; no summed power or interference is inferred.

Normal mounts: 25.4 mm outer diameter; 10 × 10 mm clear crystal. WP/RP use a 10 mm cube in a 14 mm tube. BD uses a 28 mm tube at displacement ≤2.7 mm, otherwise 41 mm. The built-in BD aperture is centred between its two axes, while its datum stays on the straight ray. Leading size prefixes scale these reference dimensions; tube length and crystal width can be overridden per optic. Custom CAD keeps its original dimensions. Tube length is visual: only p adds geometric path length.

Conventions

Azimuth and elevation are additive angles in the design root frame. Elevation stays within −90° to +90°; at a vertical direction the last azimuth is retained for the next turn. Actual reflection angles are calculated from the 3D directions.

Optics use ideal interaction planes. BS/BSC transmission starts at the hit point unless a displacement is specified. Positive displacement moves transmission away from the reflected branch; reflection stays at the original hit point. At 180° reflection the displacement uses local right. TP and beam displacers create explicit lateral offsets. Internal crystal propagation, polarization and material ray tracing are outside this layout model. Reference loss, GDD and glass thickness never alter the beam geometry.

Beam status reports collimated, converging or diverging. A Gaussian waist still has a nonzero far-field divergence. Its M² envelope is a layout aid, not a substitute for an optical design calculation.

Custom optic coordinates & defaults

The component file’s origin is the default datum. Keep it, or choose a vertex, sketch/construction point, or the centre of a circular edge or sketch circle/arc. This picks a position; it does not create a joint or infer its orientation. Use component origin restores the original datum.

The selected datum is placed at the beam interaction point. XYZ shifts use the optic frame. Rotations apply about the datum around fixed local X, then Y, then Z axes. Prefix f adds 180° to this last rotation. Source components are instanced without rescaling or moving the original. Rotation about local Z does not reverse the front and back of an optic whose faces are normal to Z.

Configure reusable components on Defaults → Default optics & components: component, datum, XYZ offsets, rotations and reference properties, then Save default. New optics have Use default checked. If no component is assigned, they use the built-in shape. Uncheck for a local copy you can customize; recheck to follow the global record again. The checkbox never changes the global default. Already built routes retain pinned settings; recheck deliberately to adopt a new default. Save the Fusion document to retain defaults.

l50, l-50 and +l50 have separate defaults; f does not change the physical key. All bs angles and signs share one default per size: bs30 and bs-90 use the same plate. All tp angles/displacements share one plate per size. OAPs share defaults by size, actual 3D bend magnitude and focal length; signs and underscore only select orientation. Legacy angle-specific splitter defaults merge with an existing canonical key taking precedence; review the retained part if older angle presets differed.

For an OAP, local +Z is its parent/blank axis and local +X points away from the parent axis toward the selected off-axis segment. Rotate the selected CAD model to match these axes and choose its chief-ray hit as the reference point. The underscore changes the target frame; it does not infer axes from arbitrary CAD geometry.

WP/RP/BD defaults ignore h/v, the trailing side sign and the BD underscore: one calibrated part can serve all orientations of the same angle/displacement and size. Local Z follows the incoming beam, and X is the secondary/walk-off side. _bd reverses the local walk-off frame by 180° about Z. Set the datum on the straight ray for BD, or where the incoming ray meets the interaction plane for WP/RP. Origin and all six placement controls remain available.

Reference budgets and connected paths

Built-in optics use adjustable example losses and GDD near 800 nm. Custom optics start at zero, with ideal 50/50 splitting for custom BS/BSC; enter your own reference values. No pulse duration or polarization is calculated. Splitters have independent T/R percentages, GDD and glass entries. WP/RP/BD call these main/secondary outputs: their built-in 49% / 49% split is an adjustable bookkeeping example, not a prediction of a polarized input. Prism GDD defaults to zero until entered. Waveplate examples use 1% loss / +50 fs²; ND uses an illustrative OD 1 (90% loss) / +100 fs²; TP uses 1% / +100 fs². Replace these examples with values for your wavelength and component. A combining BD uses the per-arm loss/GDD fields instead of splitting power again.

Total loss = 100 × [1 − product(1 − loss / 100)]. GDD adds with its sign. Glass-adjusted path = geometric length + sum[(n − 1) × effective glass thickness]. n and thickness both default to zero; nonzero thickness requires n. Effective thickness is the total distance travelled in glass, including oblique incidence or multiple passes, and already occupies that much of the geometric path. This is phase optical length, not group delay.

Budget & export combines successive paths along one arm and counts shared sections once. A reflected continuation selects the correct splitter port automatically when its parent path is selected. The result names any parent path shortened at a splitter. Independent routes can also join by position and forward direction (0.001 mm / 0.001°). Unique intermediate paths are included and listed; ambiguous connections need an explicit intermediate selection. Differing independent envelopes are not repropagated by the calculator. Export all document paths saves a single ZIP with CSV, SVG and endpoint documentation. Individual route CSVs can be imported as drafts. These are simple approximations for reference, not quantitative optical results.

Stepwise workflow

  1. Enter a line, check its beam state, configure its optics and preview.
  2. Choose Build to keep the window open, or Build & close.
  3. In Saved paths, use Start new run here at an end or reflected port, or copy its endpoint.
  4. Build the continuation. To revise the last build in the open window, use Replace route.

Settings, component defaults and endpoints persist in the Fusion document. Edit paths rebuilds the selected route. A saved route is Disconnected only if a tracked start has no existing endpoint at the same position and direction (0.001 mm / 0.001° tolerance). Built beams retain their configured colors and opacity; connection warnings do not dim the model. If the connection matches but diameter, divergence, model or reference totals changed, it shows Beam update available. Revision-only changes do not mark it outdated. Refresh beam finds suitable current endpoints, lets you choose if ambiguous, and rebuilds the beam while preserving all existing optics. Refresh upstream routes first. The top Refresh button rescans status; it does not rebuild beams. Unchecking Keep following saved paths attempts a rigid move. A changed envelope at a matching start can use Refresh beam; incompatible starts require editing. Old LOR1 packets do not contain dependency tracking.

Prepare a component once

In the component’s own file, place its optical datum at the origin. Use millimetres and the local axes below; leave shift and rotation at zero when the model already follows this convention.

ElementOriginLocal axes
Lens, polarizer, λ/2, λ/4, ND, genericBeam centre on the interaction plane+Z along transmission; X/Y span the plane.
Tweaker plateIncoming chief-ray hit on the plate+Z along the plate normal toward transmission at zero incidence; X/Y span the plate. The command tilts the target normal.
Mirror, plate splitterChief-ray hit on the front surface+Z normal toward the beam side; solid backing toward −Z.
Cube splitterCube centre / splitting-plane hit+Z transmitted; +X reflected. Internal plane Z = X.
Wollaston, Rochon, BDMain-ray datum at the ideal interaction plane+Z incoming; +X toward secondary separation / walk-off.
OAPChief-ray hit on the off-axis surface+Z parent axis toward the parent focus; +X radially outward from parent axis to off-axis segment.

All frames are right-handed: Y = Z × X. For an OAP, the origin is the off-axis chief-ray hit, not the parent vertex or blank’s rear centre. A conventional r90f50 receives light along −Z; _r90f50 sends the outgoing beam along +Z. The Inspector shows the resulting frame for each placement.

  1. Save the part, then insert it into your setup as a linked component using Fusion.
  2. Assign that occurrence in Inspector. The add-in reuses its definition without editing the source. Keep a separate source instance; hide it manually if needed.
  3. Use Preview this CAD only. X/Y/Z datum axes are red/green/blue. Check both beam legs and the actual optical surface.
  4. Adjust the datum or calibration if needed. Keep simple planning optics until ready to enable assigned CAD.

Build places components sequentially, with progress and cancellation between native operations. One expensive Fusion operation can still block temporarily. Simplify screws, threads and imported tessellation in heavy source models. Cancellation rolls back the route build; source version updates use Fusion’s normal linked-component workflow.

Full preparation, OAP and protection details: docs/COMPONENTS.md in the add-in folder.
